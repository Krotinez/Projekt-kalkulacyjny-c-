# Projekt-kalkulacyjny-c-
projekt szkolny - program kalkulacyjny - zawansowany by poradzić sobie z matematykom rozszerzoną w technikum informatycznym
## Założenia projektu
- Aplikacja graficzna realizująca obliczenia matematyczne z wykorzystaniem bibliotek języka C++
- Aplikacja obsługuje menu startowe, menu wyboru kalkulatora i menu dla karzdego kalkulatora
- Menu startu ma zawierać dwa przyciski, pierwszy odpowiedzialny za przejście do menu wyboru drugi za zakończenie działania programu
- Menu wyboru zawiera przycisk na każde menu kalkulatora i jedno do cofnięcia się do poprzedniego menu
- Ilość menu kalkulatora jest zaplanowana na przynajmniej trzy: Arytmetykę, Algebra i Geometrie
- W każdym z kalkulatorów ma być możliwe każde obliczenia z danego działu, w zakresię matury rozszeżonej.
